# Portfólio — Carlos Eduardo Braz

Site pessoal desenvolvido com HTML, CSS e JavaScript.

## Recursos
- Layout responsivo para desktop e celular
- Tema claro/escuro
- Menu mobile
- Animações de entrada
- Seção de habilidades, trajetória e projetos
- Links para projetos publicados no GitHub Pages

## Como executar
Abra o arquivo `index.html` no navegador.

## Publicação no GitHub Pages
1. Envie `index.html`, `styles.css` e `script.js` para o repositório.
2. Acesse **Settings > Pages**.
3. Em **Build and deployment**, selecione `Deploy from a branch`.
4. Escolha a branch `main` e a pasta `/root`.
5. Salve e aguarde a publicação.
